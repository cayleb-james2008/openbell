# Aliveness Inventory — OpenBell

Every motion timing and spring value comes from `rune/used/motion.ts` (`frontend/src/motionProps.ts`) and the `--dur-*` / `--ease-house` CSS tokens in `frontend/src/tokens.css`. Nothing in the first screenful plays an entrance animation on load; loops run strictly on active work (`BorderTrail` during `POST /api/collect`) and stop immediately when the pass completes; `prefers-reduced-motion: reduce` cuts drawer/CSS transitions and disables `pathLength` drawing (`MotionConfig reducedMotion="user"`).
